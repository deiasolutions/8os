## Reading order

For a reader encountering this set fresh:

1. **Start with `CHAT-13-CONVERSATION-LINEAGE.md`.** It walks the derivation in eleven steps and explains why each artifact was forced by the previous one. Without the lineage, the substantive artifacts read as four unrelated proposals.

2. **Then read `TURTLES-PRINCIPLE-v0_1.md`.** It is the high-altitude framing that ties the substantive artifacts together as expressions of a single compositional discipline.

3. **Then read the proposals in either order.** `AXIOM-8-AMENDMENT-PROPOSAL-v0_1.md` is the foundational claim; `KERNEL-ESCALATE-PRIMITIVE-PROPOSAL-v0_1.md` is the machinery enabled by it. Reading axiom 8 first makes the primitive's motivation more legible.

4. **Read `OPEN-Q-004-substrate-topology.md` last.** It is held provisionally and is the most speculative; it should be encountered after the substantive content has been absorbed.

## Relationship to existing project state

The build sequence after Block 4.7 already names: L-system fractal-plant demo, overview drafting, repo hygiene, publish track, LinkedIn article, then Block 4.8 and tier B post-publish work. **None of the chat-13 artifacts modifies that sequence.** They are inputs to Block 5+ planning and to the eventual v1.2 amendment cycle.
